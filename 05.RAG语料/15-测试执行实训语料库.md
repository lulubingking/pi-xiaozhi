# 15 测试执行实训

## 分层测试

前端构建验证 TypeScript/Vite 打包；后端 `compileall` 验证语法导入；pytest 验证现有自动化用例；API smoke 验证服务、健康检查和认证边界；真实端到端验收使用授权样本验证 OCR、分组、评分、复核、报告和导出。

## 推荐命令

```powershell
Set-Location 'E:\实训项目\AI自动批改作业智能体'
npm run build
Set-Location '.\backend'
python -m compileall app
pytest -q
```

## 结果记录

记录命令、时间、版本、样本、输出、截图/响应、失败原因和未覆盖范围。自动评分结果必须经过教师复核后再作为报告依据。

## 证据定位

参考 `backend/tests`、`验收报告` 和 `实训6-AI共创-执行测试.md`。

## 事实边界

当前已有自动化检查结果不能单独推出 OCR 准确率、评分一致性、浏览器可用性或生产稳定性。
