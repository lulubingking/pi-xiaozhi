# 17 部署与运维

## 交付结构

`部署版code/批小智/frontend-dist` 是前端静态产物，`部署版code/批小智/backend` 是后端源码与依赖说明。交付包不包含 `node_modules`、Python 虚拟环境、SQLite 数据库、上传目录、OCR 模型缓存或有效 API Key。

## 启动前检查

确认 Python 环境和 `requirements.txt`，配置运行时环境变量，执行数据库迁移或初始化步骤，再启动 FastAPI 和唯一的后台 worker。静态服务器只暴露 `frontend-dist`，API 由反向代理转发。

## 运维重点

备份数据库和上传证据；记录 worker、模型、迁移和前端构建版本；监控任务积压、失败重试、磁盘空间、SQLite 锁和报告导出；清理前按批次、文件角色和关联状态核对。

## 证据定位

查看 `部署版code/批小智/README_prod.md`、`backend/README.md`、`backend/alembic.ini` 和 `HANDOFF.md`。

## 事实边界

当前交付目录是可移交的代码包，不等于已在用户服务器完成部署、监控、备份和灾备验收。
