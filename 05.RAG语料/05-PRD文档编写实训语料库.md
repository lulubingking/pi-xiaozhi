# 05 PRD 文档编写实训

## 写作结构

PRD 至少说明背景、目标、用户角色、核心流程、数据实体、页面与接口、异常处理、权限和验收标准。批小智还应明确题目卷与学生作业的关系、批次状态、人工复核点和报告生成条件。

## 验收写法

把“支持 OCR”改写为可验证条件，例如：提交合法文件后生成任务；可以查询任务状态；识别结果可查看、修正和确认；失败时保留错误信息并允许安全重试。不要写无法由样本和证据支持的准确率。

## 证据定位

参考 `批小智_PRD_v1.0.0.md`、`04.实训指导书/AI共创过程文档/实训1-AI共创-产品需求规格说明书.md` 和 `HANDOFF.md`。

## 风险

PRD 是产品约束和验收目标，不自动证明代码已经实现；发现文档与源码冲突时，应记录冲突并以当前 HANDOFF/源码核对。
