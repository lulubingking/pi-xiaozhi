# 08 前端开发实训

## 代码结构

`src/main.tsx` 是入口，`src/App.tsx` 管理主要页面工作流，`src/api/client.ts` 负责 API 调用，`src/utils` 放置题目结构、题目布局、OCR 自动分配和评分规则输入逻辑，`src/styles.css` 负责全局样式。

## 开发验证

```powershell
Set-Location 'E:\实训项目\AI自动批改作业智能体'
npm run build
```

构建成功后检查 `dist/index.html` 和浏览器运行时错误。请求失败、空列表、上传中、任务处理中和复核保存失败都应有用户可理解反馈。

## 性能边界

避免重复请求、不稳定 effect 依赖、无界大列表和把大文件内容放入 React 状态。生产 bundle 不应包含 API Key、数据库文件、上传原图或模型缓存。

## 证据定位

查看 `src/App.tsx`、`src/api/client.ts`、`src/utils`、`package.json` 和 `vite.config.ts`。
