# 09 后端开发实训

## 代码结构

`backend/app/main.py` 创建 FastAPI 应用并挂载路由；`backend/app/api` 按认证、班级、批次、文件、OCR、评分、报告、rubric、设置和健康检查分组；`models.py` 与 `schemas.py` 定义数据和接口形状；`workflows`、`ocr_worker.py`、`grading_worker.py` 与 `report_export_worker.py` 处理异步流程。

## 开发验证

```powershell
Set-Location 'E:\实训项目\AI自动批改作业智能体\backend'
python -m compileall app
pytest -q
```

还要检查数据库迁移、SQLite 锁、任务幂等、权限过滤和错误响应。不要将测试通过解释为真实模型效果。

## 安全边界

API Key 从运行时配置读取，日志需要脱敏；认证和资源归属校验必须在后端执行，不能只依赖前端隐藏按钮。

## 证据定位

查看 `backend/app/core/config.py`、`backend/app/core/runtime.py`、`backend/app/api/deps.py`、`backend/migrations` 和 `backend/tests`。
