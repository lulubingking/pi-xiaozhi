# 07 开发任务文档编写实训

## 任务拆分

按用户路径或技术能力拆分：认证、班级/学生、批次、文件上传、OCR 任务、页面/题目分组、评分任务、复核队列、报告导出和设置。每个任务应写输入、输出、代码范围、依赖、验收命令和失败回滚。

## 依赖顺序

先确认数据模型和迁移，再实现 API schema 与路由，随后接入前端请求和状态，最后添加 worker、测试和导出验证。异步任务要单独描述状态查询与重试，不将 202 误写成同步完成。

## 证据定位

查看 `backend/app/models.py`、`backend/app/schemas.py`、`backend/app/api`、`backend/app/workflows`、`src/api/client.ts` 和 `backend/tests`。

## 风险

涉及数据删除或迁移的任务必须有精确路径、保留清单和备份；涉及模型替换的任务必须先做接口兼容和样本回归，不可仅凭速度或单次输出决定。
