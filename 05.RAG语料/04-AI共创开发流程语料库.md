# 04 AI 共创开发流程

## 推荐流程

先阅读 `HANDOFF.md` 与当前 PRD，确认目标和非目标；再检索 UI/UX、技术文档与源码；将任务拆成可验证的小步；执行前端构建、后端编译、自动化测试和必要的 API smoke；最后单独记录真实模型与人工验收缺口。

## 协作规则

AI 生成的代码必须回到当前源码、接口和测试中核对。对文件删除、数据清理、模型替换、API Key 和生产部署，先确认具体路径、依赖和回滚方案。不要通过“看起来合理”补齐没有证据的接口、指标或业务规则。

## 交付记录

每项工作记录：事实依据、改动文件、执行命令、验证结果、未覆盖范围和风险。交付包不包含依赖缓存、数据库、上传样本和有效密钥。

## 证据定位

根目录 `SKILL.md` 规定实训文档的六个部分和 PowerShell 验证标记；`HANDOFF.md` 规定当前产品边界。
