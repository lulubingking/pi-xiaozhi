# 批小智数据说明

本交付包不复制真实学生作业、教师信息、上传原件、SQLite 运行库和 OCR 模型缓存。

## 数据分类

- `question_paper`：教师上传的题目文件，用于题目结构和参考答案配置。
- `student_work`：学生作业文件，用于学生页 OCR、页分组和答案确认。
- 受控 OCR 样本：存放在原开发项目的数据与实验目录中，不作为部署包内容。

## 使用原则

1. 测试时使用脱敏样本，不把真实学生信息提交给外部模型。
2. 运行数据由后端默认写入 `backend/data/pixiaozhi.db` 和 `backend/data/uploads`。
3. 不手动删除正在 OCR、已形成答案、已生成评分或已导出报告的文件。
4. 清理应通过 WebApp 的文件/批次清理接口，并保留审计边界。
